# Celebrity Bingo

Celebrity spin-wheel bingo game.

## npm Commands

| Command | What it does |
|---|---|
| `npm install` | Install dependencies (once, or after pulling changes) |
| `npm start` | Runs `node server.js` — open in a browser |
| `npm run dev` | Launches the **Electron wrapper** instead |

**Careful:** `start`/`dev` are flipped here compared to most other
projects — `start` is the web server, `dev` is the desktop shell. No build
script (not packaged into an installer). See the full
[npm cheat sheet](../NPM-CHEATSHEET.md) for how this compares to other
projects.
